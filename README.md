### Instructions

1. **Download and Run the Script**:
   To download and run the `T3rn.sh` script, use the following command:

   ```bash
   wget https://raw.githubusercontent.com/choir94/T3rn/refs/heads/main/T3rn.sh && chmod +x T3rn.sh && ./T3rn.sh
   ```

2. **Cek Logs**
   Log Monitoring: After the executor is running, you can monitor the logs using the following command:

